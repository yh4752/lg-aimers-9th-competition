# 977점 이후 전문가 포트폴리오 설계

## 목적

현재 제출물 `catboost_player_stats_3seed_v1`은 Public Score
`977.3809532715`를 기록했다. 기존 TabM 제출 `872.3920184667`보다
`104.9889348048`점 높으므로 선수 통계와 CatBoost 잔차 모델은 유지할 가치가
있다. 다음 목표는 검증되지 않은 모델 수를 늘리는 것이 아니라, 현재 모델과
오류 원인이 다른 후보를 순서대로 검증해 1차로 1000점, 이후 1030~1070점
구간에 진입하는 것이다.

실험 순서는 다음과 같이 고정한다.

1. 최근 시즌 + 시간 감쇠 다년 모델
2. R/F 경기 유형 전문가
3. 실패 유형 전문가
4. 이종 모델 잔차 앙상블

각 단계는 독립 후보다. 한 단계가 거절되더라도 이후 단계의 입력을 만들 수
있으며, 거절된 후보는 제출 패키지에 포함하지 않는다.

## 고정 기준선

- Public 기준선: `977.3809532715`
- 모델: `c1_anchor_residual`
- 구성: 동일 구조 CatBoost 3시드 평균
- 제출 ZIP SHA-256:
  `8bc33042b9258049f905df0c733b1153d1cedfac39cb0732b2a7e154629d779a`
- 시간 검증 fold: 2021→2022, 2022→2023, 2023→2024
- 기존 OOF weighted gain: `0.0008375137395728018`
- 기존 OOF worst-fold gain: `0.0003439904301012764`

기준선의 코드, frozen state, 모델 파일은 변경하지 않는다. 새 후보는 기준선
예측을 입력으로 받아 추가 개선만 증명한다.

## 공통 원칙

### 평가 데이터 독립성

한 평가 행의 예측에는 다음 정보만 사용한다.

- 해당 행의 원본 변수와 행 내부 파생변수
- 공식 학습 데이터로 미리 계산한 통계
- 공식 학습 데이터로 학습한 모델과 고정된 가중치

평가 데이터의 다른 행, 전체 평균, 빈도, 순위, 같은 선수·팀·경기의 평가 행
집계는 사용하지 않는다. 모든 후보는 singleton, shuffle, reverse, companion,
여러 batch size에서 같은 행의 예측이 허용 오차 `1e-6` 안에서 동일해야 한다.

### 시간 검증

모든 학습 통계와 모델은 fold의 검증 연도보다 앞선 시즌만 사용한다.
검증 연도별 후보 가중치를 따로 최적화한 뒤 평가 데이터에 임의로 적용하지
않는다. 최종 가중치는 세 fold의 순차 OOF 결과로 한 번만 선택한다.

### 제출 패키징

후보 상태가 `accepted`가 아니거나, 수용 근거·모델·코드·규칙 검토의 현재
해시가 예상값과 다르면 패키징 진입점을 중단한다. 최종 후보는 공식 5행
샘플 실행, 행 독립성 감사, 10분 추론 제한 및 28GB RAM 제한을 모두 통과해야
한다.

## Stage T3: 시간 이중 모델

### 모델 구성

각 fold에서 두 개의 CatBoost 잔차 모델을 만든다.

- `recent`: 검증 연도의 직전 시즌 행만 학습
- `multi_decay`: 검증 연도 이전의 모든 시즌을 사용하되 오래된 행에 시간
  감쇠 가중치를 적용

시간 감쇠 후보는 `0.35`, `0.55`, `0.75` 세 개로 제한한다. 검증 직전 시즌의
`age`를 0으로 정의하고 각 학습 행에 `decay^age`를 적용한다. 최근 모델과
다년 모델의 혼합 후보는 recent 비중 `0.70`, `0.80`, `0.90`만 비교한다.

구조 선택은 시드 3407 하나로 수행하고, 구조가 통과한 경우에만 시드 42와
2026을 추가한다. 따라서 구조 탐색에서 불필요한 3시드 반복을 피한다.

### T3 수용 기준

- 세 fold 가중 Brier가 기준선보다 `0.00015` 이상 개선
- 2023→2024 fold 개선이 양수
- 어느 fold도 `0.00005`보다 크게 악화되지 않음
- 표본 5000개 이상인 주요 구간의 최대 악화가 `0.0005` 이하
- 3시드 중 적어도 2개가 단일 시드 기준선을 악화시키지 않음

T3가 통과하면 이후 단계의 기준 예측은 T3로 교체한다. 거절되면 기존 977점
모델을 계속 기준으로 사용한다.

## Stage E-RF: R/F 경기 유형 전문가

`game_type`은 현재 행에 포함된 값만 사용한다. 공통 기반 모델을 유지하면서
R과 F 각각에 작은 residual 전문가를 학습한다. 먼저 F 전문가만 적용하는
후보, 다음으로 R/F 두 전문가를 적용하는 후보를 비교한다.

전문가가 없는 구간이나 표본 수 기준을 충족하지 못한 구간은 기반 모델의
확률을 그대로 사용한다. 평가 데이터에서 구간 빈도를 계산해 가중치를
바꾸지 않는다.

### R/F 수용 기준

- 전체 weighted Brier `0.00010` 이상 개선
- R과 F 중 어느 구간도 `0.00010`보다 크게 악화되지 않음
- 세 fold 중 두 fold 이상에서 전체 개선
- 가장 최근 fold에서 F 구간 개선이 양수

## Stage E-Fail: 실패 유형 전문가

기존의 단일 multiclass 후보를 반복하지 않는다. 공식 학습 데이터에서
정의 가능한 `middle`, `reverse`, 기타 실패를 one-vs-rest 보조 모델로 각각
학습한다. 최종 성공 확률은 기반 성공 확률과 실패 전문가의 OOF 예측을
작은 residual gate로 결합한다.

전문가별 가중치는 `0.05`, `0.10`, `0.15`만 검토하며, 각 실패 유형의 표본이
fold별 최소 기준을 충족하지 않으면 해당 전문가를 건너뛴다.

### 실패 전문가 수용 기준

- 전체 weighted Brier `0.00008` 이상 개선
- 세 fold 중 두 fold 이상에서 개선
- 최근 fold가 악화되지 않음
- 각 실패 유형의 표본 5000개 이상 구간에서 최대 악화 `0.0003` 이하
- 확률 합성과 clip 전후에 NaN, infinity, 범위 위반이 없음

## Stage H: 이종 잔차 앙상블

CatBoost 기반 후보가 확정된 뒤 XGBoost와 LightGBM을 각각 하나의 구조로만
학습한다. 단독 점수보다 CatBoost OOF 오차와의 차이를 우선한다. 후보의 OOF
잔차 상관이 너무 높거나 혼합 후 개선이 없으면 즉시 거절한다.

혼합 비중은 이종 모델 합계 `0.05`, `0.10`, `0.15`만 비교한다. XGBoost와
LightGBM을 모두 넣는 경우에도 총 이종 비중은 `0.15`를 넘지 않는다.

### 이종 앙상블 수용 기준

- 전체 weighted Brier `0.00005` 이상 개선
- 어느 fold도 `0.00003`보다 크게 악화되지 않음
- 최근 fold 개선이 음수가 아님
- CatBoost와 완전히 같은 예측을 내는 모델은 제외

## 진단 산출물

각 단계는 모델 학습 결과와 별도로 동일한 형식의 진단 자료를 남긴다.

- fold별 전체 Brier와 기준선 대비 gain
- `game_type`, 성공/실패 유형, 선수 표본 수, 손잡이 조합, 볼카운트 구간별
  Brier와 행 수
- 확률 구간별 calibration 표
- 모델 간 OOF 예측·잔차 상관
- 선택된 가중치와 선택 근거
- 행 독립성 감사 결과
- 재시작 가능한 resume와 사람이 확인할 review ZIP

리더보드 점수는 실험 선택에 사용하지 않고, 수용된 후보의 외부 확인값으로만
기록한다.

## 실행 예산과 중단점

Kaggle T4 두 장과 최대 30시간을 한 번에 사용하지 않는다.

- T3 구조 선택: 최대 8시간
- T3 다중 시드 확인: 최대 6시간
- R/F 전문가: 최대 6시간
- 실패 유형 전문가: 최대 5시간
- 이종 앙상블과 최종 fit: 최대 5시간

각 단계는 2~4시간 단위의 안정 snapshot을 만들고, 세션 종료 시 마지막으로
검증된 resume 하나만 전달한다. 한 단계가 조기 거절되면 남은 시간을 다음
독립 단계로 넘긴다.

## 제출 전략

1. T3가 수용되면 T3 단독 제출로 1000점 돌파 여부를 확인한다.
2. R/F 전문가가 추가 수용되면 T3+R/F 제출을 만든다.
3. 실패 전문가와 이종 앙상블은 각각 수용 근거가 있을 때만 누적한다.
4. Public 점수가 떨어졌다는 이유만으로 OOF에서 거절된 후보를 되살리지
   않는다.
5. 최종 제출은 현재 977점 ZIP을 항상 되돌릴 수 있는 기준선으로 보존한다.

## 성공 기준

- 기술 성공: 모든 후보가 중단·재개 가능하고 행 독립성 및 제출 환경 검사를
  통과
- 실험 성공: 적어도 하나의 독립 후보가 공통 OOF gate 통과
- 리더보드 1차 목표: 1000점 초과
- 리더보드 2차 목표: 1030~1070점
- 1100점대는 시간·경기 유형·실패 유형 중 둘 이상의 독립 개선이 함께
  검증됐을 때만 현실적인 목표로 간주
